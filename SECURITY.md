# Security policy

## Reporting a vulnerability

Please do not publish exploitable details, credentials, or sensitive server output in a public issue. Use the repository host's private vulnerability-reporting feature if enabled; otherwise contact the maintainers through a verified private channel listed in the repository profile.

## Scope

Security-relevant reports include unsafe archive handling, checksum bypasses, unintended destructive file operations, privilege-handling problems, and accidental disclosure of secrets.

## Safe use

Run only after reviewing the script. Obtain release archives and checksums from official Mattermost sources. Do not paste credentials, access tokens, private configuration, or database contents into issues or discussions.
